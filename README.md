## 이 저장소에 있는 것

- `app/`: 적용 시점의 Python/HTML/JS/CSS 소스, 공개 정적 텍스트와 레시피 시드. 개인 설정은 없습니다.
- `tests/`: 게임 실행 없이 검사하는 선별 회귀 테스트.
- `scripts/`: 원본 배포본에 소스를 적용하는 도구, 명시적 데이터 위치 지정, 선택형 승인 실행기 설치.
- `config/`: 비밀과 개인 데이터를 포함하지 않는 설정 예시.
- `tools/analyze-connector-log.py`: 로컬 로그만 읽는 시간·휴식 감사 도구.
- `diagnostics/`: 비활성 진단 소스. 앱 시작 경로에 연결하지 않습니다.
- `MANIFEST.json`: 포함 파일의 SHA-256. 해당 문서 자체는 목록에서 제외합니다.

## 중요 제한

이 저장소만 내려받아 바로 실행하는 형태는 아닙니다. 원본 MobiWorks Beta 1.0.11 배포본의 `python/`, WebView2 로더, 아이콘·글꼴 파일을 별도로 준비해야 합니다. 외부 실행 파일과 개인 실행 데이터를 공개 저장소에 복제하지 않았습니다. 자세한 재구성 절차와 출처는 설치 문서를 보세요.

휴식은 **앱 호출 억제 실험**입니다. 게임 연결 해제나 1시간 제한 초기화를 보장하지 않습니다. 관찰 누적시간도 게임 타이머가 아닙니다. 확인창은 사용자가 게임에서 직접 확인하고, 복구 후에도 시작 버튼을 별도로 누릅니다.
