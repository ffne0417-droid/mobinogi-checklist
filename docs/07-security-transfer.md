# 보안·이관·복구

## 공개 저장소 범위

이 저장소는 사용자 요청으로 기존 공개 `mobinogi-checklist` 내용을 교체한 것입니다. 비공개 저장소로 전환한 것이 아닙니다. 체크리스트의 기존 `index.html`은 기본 브랜치에서 제거하고 Git 이력과 `archive/checklist-before-overlay-20261024`에 보존했습니다. 이슈/설정/배포 서비스 전체를 삭제한 것은 아닙니다.

다음은 올리지 않습니다.

- 실제 `data-location.json`, `lite.json`, settings/queue/history/프리셋/캐릭터 캐시.
- 커넥터 응답 원문, `last-response.json`, 게임 로그, 클릭 좌표 기록, 개인 스크린샷·커버.
- 토큰, 원격 인증키, DPAPI 봉투, 브라우저 세션/프로필.
- `python/`, 게임 CLI, WebView2 DLL, 다운로드한 `key_macro.exe`/ATK 프로그램, 제작된 클릭 exe.
- 레시피 시드 외의 개인 데이터 JSON. 공개 예시는 빈 큐 생성이나 자동 실행을 하지 않음.

이전 체크리스트의 Git 이력은 유지되므로 '내용 교체'가 과거 이력의 비밀 제거를 뜻하지 않습니다. 이전 파일에 비밀이 있었다면 별도 조사와 키 폐기가 필요합니다.

## 로컬 인증

앱은 실행 포트와 PID를 `lite.json`에 쓰고, 실행별 토큰을 로컬 페이지에 제공합니다. 외부에 포트를 공개하지 마세요. API가 필요하면 동일 출처와 `X-Requested-With=mobiworks`, `X-MobiWorks-Token`을 사용하되 토큰을 메모리에서만 취급합니다. 토큰값·페이지 원문을 콘솔, 문서, 이슈에 붙이지 않습니다.

원격 터널/방송/메일 기능은 원본에 존재하지만 새 설치 기본 동작으로 켜지 않습니다. 사용자가 별도 권한 범위를 결정해야 합니다. 원격 실행은 날개/재료 소비를 일으킬 수 있습니다.

## 데이터 이관

앱을 정지·종료한 뒤 데이터 루트의 개인 백업을 비공개 매체로 옮깁니다. 큐의 실제 게임 등록 상태와 새 PC 접속 캐릭터가 일치하는지 확인하지 않고 시작하면 안 됩니다. DPAPI 보호 키는 Windows 사용자에 묶여 있어 다른 PC에서 그대로 쓸 수 있다고 가정하지 않습니다. 새 PC에서 재설정합니다.

절대 경로가 든 `data-location.json`은 새 PC에서 다시 생성합니다. `lite.json`과 오래된 PID/포트는 복사하지 않습니다. 새 관찰기를 0부터 시작해도 게임 이용시간이 초기화되는 것은 아닙니다.

## 롤백

- 코드: 설치 스크립트가 남긴 백업과 변경 전 파일 목록을 대조해 앱 종료 상태에서 복원. 새로 추가된 파일은 목록을 보고 수동 판단하며 폴더 전체 삭제 금지.
- 개인 데이터: 변경 직전 비공개 백업 사용. 코드 롤백이 게임 등록/수령을 되돌리지는 못함.
- 체크리스트: 백업 브랜치에서 `index.html` 복원 또는 교체 커밋을 되돌리는 새 커밋 생성. 강제 push나 이력 초기화 필요 없음.

## 출처와 라이선스

기반은 MobiWorks Beta 1.0.11 배포본입니다. 원본 저작권·고지·파일 내 주석을 유지했습니다. 이 작업으로 원본 전체에 MIT 등 새 라이선스를 부여하지 않습니다. 원본 최상위 라이선스를 확인하지 못했으므로 재배포/상업 이용 권한을 자동 추정하지 마세요.

WebView2 라이선스 텍스트와 글꼴 README의 OFL 고지는 유지하지만 바이너리는 제외했습니다. 각 외부 구성품은 원본 배포 경로와 해당 라이선스를 따릅니다. 게임/ATK 실행 파일을 클론하거나 드라이버를 복제한 프로젝트가 아닙니다.
