# 전체 구조와 기능

## 실행 구조

```text
사용자가 실행 / 선택형 승인된 작업 스케줄러
  └─ python/pythonw.exe app/server.py
       ├─ 로컬 HTTP 서버 + 실행별 인증 토큰 + lite.json
       ├─ overlay.py → webdrawer.py → overlay-tasks.html
       │                             └─ 원본 index/drawer/board UI 재사용
       ├─ workqueue.py → cli_transport.py → 공식 MabinogiMobile_CLI.exe
       │                    ├─ transportquiet.py: 휴식 중 호출 진입 차단
       │                    └─ connectorusage.py: 실제 명령 호출 시간 관찰
       └─ store.py / folio/engine.py → 별도 로컬 데이터 폴더
```

오버레이 작업 창은 별도의 큐 엔진을 만들지 않고 원래 작업 추가·그룹·보드 API를 재사용합니다. 본 앱과 오버레이에서 같은 카드 ID와 진행량을 봅니다. 큐에 담기와 실행은 별개이며 담기만으로 자동 시작하지 않습니다.

## 화면별 기능

- 작업: 채집·제작·가공·수령·연주·알림, 검색·분류, 수량·가능 최대 계산, 담은 항목 수정/삭제.
- 툴바: `★ | 전체 · 채집 · 제작 · 가공 · 수령 · 연주 · 알림`, 담을 곳과 프리셋을 좁은 드롭다운으로 선택.
- 그룹: 이름·반복·오류 처리·항목 편집, 복제·해체·삭제. 실행 중 편집은 기존 제약 유지.
- 프리셋: 그룹 범위 또는 전체 구성 저장, 선택·편집·삭제·덧붙이기, 종류 필터와 순서 변경. 저장된 원본과 큐에 담은 복사본은 분리.
- 재료 준비: 총 보유량 목표, 가방+창고 차감, 부족 재료 준비와 가능한 만큼 제작. 불명확/순환/지원하지 않는 반복은 이유를 표시하고 임의 계산하지 않음.
- 가공: 시설별 현황·등록·수령 경로. 등록 수량과 수령 수량을 구분하며 작업 화면과 글자 크기·두께를 맞춤.
- 관리: 원본 보드, 시작/정지, 최근 상태·결과 기록, 오류별 복구, 실제 휴식 카운트다운과 명령 누적 관찰값.
- 음악: 지원 악보·악기 조회, 첫 표시 자동 확인과 수동 새로고침, 즐겨찾기·최근 목록·동명 악보 구분·커버 관리. 연주는 기존 엔진 사용.
- 배치: 게임 창 추적, 위치·방향·테마 및 이름 있는 레이아웃 저장/복원 관련 코드. 모든 화면 크기에서 게임 버튼 위치를 시각 탐지하는 기능과는 다름.

## 음악 목록이 적게 보이는 이유

음악 화면은 커넥터가 제공하는 악보 목록을 표시합니다. 가방에 있는 모든 악보를 화면 인식으로 수집하지 않습니다. 직접 작곡된 악보의 AI 커넥터 연주는 10/15 업데이트에서 제한되었습니다. 따라서 새로고침으로 해결되는 캐시 지연과 게임 API가 제공하지 않는 악보는 구분해야 합니다. [공식 업데이트](https://mabinogimobile.nexon.com/News/Update/3563175)

조회 실패 시 이전 캐시를 보존하고 마지막 확인 시각과 목록 범위를 표시합니다. 자동 확인은 큐/연주 실행 중 경합을 피하도록 제한합니다. 수동 새로고침은 자동 표시가 지연될 때 사용하는 보조 수단입니다.

## 핵심 파일

| 파일 | 책임 |
|---|---|
| `app/server.py` | 로컬 인증·API·수명 관리·큐와 관찰기 결합 |
| `app/store.py`, `app/datadir.py` | 데이터 저장·검증·명시적 설치별 데이터 경로 |
| `app/workqueue.py` | 큐·그룹·실행·가공 등록/수령·오류 복구 |
| `app/cli_transport.py` | 공식 CLI 호출·응답 해석·메타데이터 감사 |
| `app/transportquiet.py`, `app/connectorbreak.py` | 전체 앱 호출 억제와 안전 경계 휴식 |
| `app/connectorusage.py` | 완료된 4종 명령 시간·불완전 표식·직접 확인 기준점 |
| `app/overlay.py`, `app/webdrawer.py` | Windows 오버레이 호스트·WebView 창 |
| `app/ui/js/overlay-*.js`, `queue-history.js` | 오버레이 구성·관찰 상태·복구 UI |
| `app/presets.py`, `app/workfavorites.py` | 프리셋·작업 즐겨찾기 |
| `app/folio/engine.py`, `app/ui/folio/` | 음악 조회·연주·커버·음악 UI |
| `app/game_autostart.py` | 선택형 게임 프로세스 감시 실행기. 큐 자동 시작 아님 |

개인 데이터 파일과 현재 실행 PID/포트는 소스가 아닙니다. 포트를 고정값으로 기억하지 말고 설치 데이터 폴더의 `lite.json`을 매번 읽습니다.
