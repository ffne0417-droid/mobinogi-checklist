# 변경 이력과 채택 상태

기존 대화와 검수 기록을 현재 소스에 대조한 요약입니다. 과거 시도·현재 구현·실제 게임 검증을 구분합니다.

## 10/11–10/12: 원본 화면 재사용

- 별도 Tk 작업추가 시안에서 원본 HTML/JS 작업추가 재사용으로 전환. 과거 Tk 화면은 현재 주 경로 아님.
- 작업 창에 원래 종류·검색·수량·그룹·담긴 항목 편집 유지.
- 그룹 편집/삭제와 프리셋 선택·저장·덧붙이기·편집·삭제 확장.
- 프리셋 종류 필터·길게 누르기 순서 변경·총 보유량 목표·부족 재료 준비/부분 제작.
- 관리 메뉴에서 기존 보드 재사용, 작업/관리 상호 배타 전환, 창 크기 조절과 늦게 도착한 닫기 응답 경합 보정.

## 10/15–10/16: 가독성과 관찰

- 담을 곳/프리셋 드롭다운, 별표 즐겨찾기와 종류 탭, 가공 글자 크기·두께 통일.
- 음악 첫 표시 자동 확인, 수동 새로고침 보조 경로, 마지막 확인 시각과 지원 악보 범위 표시.
- 상태를 실제 실행/가공 대기/사용자 중단/오류/휴식으로 분리. 선택한 그룹/프리셋 ID만 복원하고 실행은 복원하지 않음.
- 실행 결과 이력, 안전한 실패 항목 대기로 복구, 명시적 시작 분리.
- 관리 폰트·버튼 겹침 보정: 세로 flex, 자동 높이 헤더, 제한된 기록 스크롤, 남은 보드 높이 보장.

## 실행 경로 정리

- `app/data-location.json`을 통해 본 앱·오버레이·게임 자동 실행기가 같은 데이터 루트를 사용.
- 현재 PC는 별도 runtime/MobiWorks 폴더 사용. 과거 LOCALAPPDATA의 오래된 큐를 잘못 여는 문제 방지.
- 사용자가 승인한 고정 작업 스케줄러를 통한 선택형 관리자 실행. UAC 전역 해제 아님.
- 자동 수령 담기는 원래 설정 기능. 기대하지 않은 카드 조사 시 먼저 이 설정과 프리셋 준비를 대조.

## 10/17 이후: 입력 실험

- 일반 권한 클릭/키 입력은 반환 성공과 실제 게임 반응이 달랐음.
- 게임과 도우미 권한, DPI/다중 모니터/client 좌표, 실제 커서 위치를 비교.
- 제한된 관리자 단일 채팅 클릭 성공 사례 존재. 가변 화면 전체 대응이나 확인창 자동 처리 성공으로 일반화하지 않음.
- 기존 임의 좌표·확인창 도우미 실행 파일은 이번 패키지에서 제외. 진단 소스 중 읽기/마우스 관찰만 선별.

## 10/24: 전체 호출 억제 감사와 누적 관찰

- 45분/300초 설정을 확인. 실제 5분 quiet 구간의 admitted/finished=0 확인.
- 2분/5분 시험 모두 제한 재발. '쉬면 타이머 초기화' 추정은 기각하고 누적 실제 명령 시간 가설로 설명 수정.
- `connectorusage.py` 추가: 4종 실행 명령 완료시간 저장, 진행 중 별도, 누락/겹침 표식, 직접 확인 기준점.
- 제한 감지 시 게임 조회 이전 시작 차단. 사용자 확인 기록→진행량 유지 복구→별도 시작.
- 재시작 때 재료 부족 등 오류 카드가 자동 pending으로 돌아가지 않게 수정. 그룹 오류도 보존.
- 휴식 토글이 사용자 300초 설정을 기본120초로 덮어쓰지 않도록 수정.
- 휴식 중 사용자 정지 뒤 후속 조회가 새로 나가지 않도록 보정.
- 정지 상태 정상 재기동으로 적용. 재기동 전후 카드 JSON 동일, 큐 running=false 확인.

## 앞으로 자동으로 하지 않는 것

10분 휴식 시험, 55/5 전환, 게임 AI 설정 토글, 확인창 자동 입력, 제한 반복 재시도, 장기 감시 재활성화는 현재 구현 완료/승인된 후속 작업이 아닙니다.
